## Featured Project

### SMART Planner — `smart-planner`

A cross-platform planner for tasks, habits, goals, prayer times, and university
tracking, with 7 themes and an immersive, offline-first Android experience.

Built with **React 18 + TypeScript + Vite + Tailwind CSS**, shipped on:

- **Android / iOS** — Capacitor 8 (edge-to-edge immersive fullscreen)
- **Desktop** — Electron 31 + better-sqlite3 backend
- **Web** — same renderer, IndexedDB storage

[View the repository →](https://github.com/ahmedmegahed20/smart-planner)
